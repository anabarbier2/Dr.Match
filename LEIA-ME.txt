PROJETO DE CADASTRO DE MEDICOS - DJANGO

ESTRUTURA BASEADA NO PROJETO taxi.zip DO PROFESSOR.

1. Abra esta pasta no Visual Studio Code.
2. Abra Terminal > New Terminal.
3. Crie o ambiente virtual:
   python -m venv venv
4. Ative no Git Bash:
   source venv/Scripts/activate
5. Instale as dependências:
   python -m pip install -r requirements.txt
6. Crie as migrações e o banco:
   python manage.py makemigrations app
   python manage.py migrate
7. Inicie o servidor:
   python manage.py runserver
8. Baixe o Thunder client e faça:
   GET http://127.0.0.1:8000/csrf/ *para pegar o token*, aperte send e vá em Headers de onde aparece o resultado e copie o token até o primeiro ";"
9. Abra outra request e faça:
   POST http://127.0.0.1:8000/medicos/ e no Headers coloque nessa ordem:
   Header:              value:
   X-CSRFToken          O token completo copiado
   Cookie               csrftoken=TOKEN_COMPLETO
   Content-Type         application/json
10. Abra no navegador a url http://127.0.0.1:8000/cadastro/ , faça um cadastro e se der certo a api conectou

API (JSON):
GET    http://127.0.0.1:8000/app/medicos/
GET    http://127.0.0.1:8000/app/medicos/1/
POST   http://127.0.0.1:8000/app/medicos/
PUT    http://127.0.0.1:8000/app/medicos/1/
DELETE http://127.0.0.1:8000/app/medicos/1/
GET    http://127.0.0.1:8000/app/csrftoken/

POST/PUT recebem JSON com os campos:
{
  "nome": "Ana Silva",
  "crm": "12345-MS",
  "especialidade": "Cardiologia",
  "telefone": "67999990000",
  "email": "ana@example.com",
  "convenio": "Particular"
}
